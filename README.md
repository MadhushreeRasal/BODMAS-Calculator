# BODMAS Calculator

A simple, interactive, web-based calculator designed to make everyday calculations easier by following the BODMAS rule.

 **Live Demo:** [BODMAS Calculator](https://madhushreerasal.github.io/BODMAS-Calculator/)

## About the Project

The BODMAS Calculator is a beginner-friendly web development project that performs basic arithmetic calculations while following the correct order of mathematical operations.

Instead of calculating each operation from left to right, the calculator processes multiplication and division before addition and subtraction, following the BODMAS convention.

Whether it's a quick calculation or a slightly longer arithmetic expression, Stress Buddy takes care of the calculation so you don't have to!

## Features

* Basic Arithmetic Operations: Perform addition (+), subtraction (−), multiplication (×), and division (÷).
* BODMAS Implementation: Automatically processes multiplication and division before addition and subtraction.
* Real-Time Input: Build mathematical expressions using the on-screen calculator buttons.
* Backspace Functionality: Remove the last entered character from the display.
* Interactive Interface: Simple and user-friendly calculator layout.
* Responsive Design: Designed to provide a convenient experience across different screen sizes.

## Technologies Used

* HTML5 – Structure and layout of the calculator.
* Tailwind CSS – Styling and responsive interface design.
* JavaScript – Input handling, expression processing, and arithmetic calculations.
* Remix Icon – Calculator interface icons.

## Understanding BODMAS

BODMAS is a mathematical rule that determines the order in which operations should be performed when solving an expression.

It stands for:

| Letter | Meaning                   |
| :----: | ------------------------- |
|    B   | Brackets                  |
|    O   | Orders (Powers and Roots) |
|    D   | Division                  |
|    M   | Multiplication            |
|    A   | Addition                  |
|    S   | Subtraction               |

**Note:** This project implements a simplified version of BODMAS and currently supports basic arithmetic operations without brackets or powers.
